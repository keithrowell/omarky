# 0005 Headings in iA Writer Quattro S Bold

Compared h1/h2 in Quattro S Bold, Duo S Bold and Mono S Bold on `prose.md` (gruvbox, 1400×1000,
zoomed crops). Duo and Mono set noticeably wider and read as shouting next to the Quattro body;
Quattro S Bold is tighter and belongs to the same family as the prose, so headings bind to their
text. Mono stays for structure: alert titles, language badges, table headers and h6 labels.

The scale is 1.25 from the reading body size: h1 +3 steps, h2 +2, h3 +1, h4 +0.5, h5 body size in
the dim tier, h6 small uppercase tracked. `OMAREAD_HEADING_FONT="Family/Style"` remains as a dev
switch for future comparisons.
