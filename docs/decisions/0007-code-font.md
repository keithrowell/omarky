# 0007 Code in iA Writer Mono S

Compared iA Writer Mono S with JetBrainsMono Nerd Font on `code.md` (gruvbox, same size and
leading). JetBrains Mono is heavier with a taller x-height, so code blocks shouted over the
Quattro prose, and its ligatures turn `->` into an arrow and `===` into a triple bar, which is
wrong for a reader whose job is to show exactly what the file says. iA Writer Mono S is the
Quattro family's mono: lighter, calm, and it sits well next to the body text.

Code is set at 0.84 of the body size with 1.5 leading. JetBrainsMono Nerd Font is still used,
only for icons (octicons).
